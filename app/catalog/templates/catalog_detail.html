Installer le complément dans Word

Le fichier téléchargé (eloignement-word.xml) indique à Word où trouver le complément ; tout le reste est servi par ce site. Word doit être fermé pendant l'installation.

Windows

  1. Enregistrez le fichier dans votre dossier Documents, où il doit rester.
  2. Ouvrez l'invite de commandes (touche Windows, tapez cmd) et collez :
    reg add "HKCU\Software\Microsoft\Office\16.0\WEF\Developer" /v Eloignement /t REG_SZ /d "%USERPROFILE%\Documents\eloignement-word.xml" /f
    Aucun droit d'administrateur n'est nécessaire.
  3. Ouvrez Word : le bouton Éloignement apparaît dans l'onglet Accueil.

Mac

  1. Dans le Finder, menu Aller > Aller au dossier, saisissez ~/Library/Containers/com.microsoft.Word/Data/Documents/wef (créez le dossier wef s'il n'existe pas).
  2. Déposez-y le fichier téléchargé.
  3. Ouvrez Word, puis un document : le bouton Éloignement apparaît dans l'onglet Accueil (sinon dans Insertion > Compléments > Mes compléments).

Première utilisation

Le volet demande une connexion MirAI : Se connecter ouvre la fenêtre du SSO. Ensuite, Nouvel acte depuis Éloignement propose les modèles de votre préfecture.

Retirer le complément

Windows : reg delete "HKCU\Software\Microsoft\Office\16.0\WEF\Developer" /v Eloignement /f. Mac : supprimez le fichier du dossier wef. Puis relancez Word.

Pour un déploiement à tous les agents d'un service, l'installation se fait par le poste de travail (stratégie de groupe sous Windows, outil de gestion des Mac) : demande à adresser au support informatique.
